# TPro Contracting

## Project Overview
TPro Contracting is a professional contracting services website that offers a variety of construction and renovation services. The website is built to provide potential customers with an overview of services, testimonials, and contact information.

## Features
- **Service Listings:** Detailed descriptions of the services offered.
- **Client Testimonials:** Feedback and reviews from previous clients.
- **Contact Form:** Allows users to contact the business for inquiries.
- **Responsive Design:** Optimized for mobile and desktop viewing.

## Setup Instructions
1. **Clone the repository:**
   ```bash
   git clone https://github.com/tmbinod007/Tprocontracting.git
   ```
2. **Install dependencies:** (Make sure you have Node.js installed)
   ```bash
   npm install
   ```
3. **Start the development server:**
   ```bash
   npm start
   ```
4. **Open your browser** and navigate to `http://localhost:3000` to view the project.
